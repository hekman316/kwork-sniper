# Kwork Sniper 🎯

Лёгкий бот, который следит за лентой проектов на [Kwork](https://kwork.ru/projects)
по выбранным категориям и присылает **новые** проекты в Telegram — заголовок,
бюджет, число откликов и прямую ссылку. Чтобы успевать в первую пачку откликов.

- ⚡️ Простой HTTP-поллинг публичной ленты Kwork (без авторизации, без Selenium/Playwright).
- 🔁 Антидубли на SQLite — не шлёт один проект дважды даже после перезапуска.
- 🔎 Фильтры по ключевым словам, бюджету и числу откликов.
- 🤫 На первом запуске «засевает» текущие проекты молча — без спама.
- 🔐 Все секреты — только в локальном `.env`, в репозиторий не попадают.

> Личный инструмент для удобства фрилансера. Опрашивайте ленту разумно
> (интервал 60–90 сек) и соблюдайте правила Kwork.

---

## Как это работает

```
каждые N секунд:
  POST https://kwork.ru/projects  (c=<категория>&page=<n>, X-Requested-With: XMLHttpRequest)
        → JSON-лента проектов
  → отбрасываем уже виденные (SQLite)
  → фильтруем по ключам / бюджету / числу откликов
  → новые отправляем в Telegram
```

Источник данных — тот же AJAX-запрос, что делает сам сайт при подгрузке ленты.
Логика получения изолирована в [`kwork_sniper/kwork.py`](kwork_sniper/kwork.py): если
Kwork поменяет API — править нужно только этот файл.

## Быстрый старт (5 шагов)

### 1. Установка
Нужен Python 3.10+.

```bash
git clone https://github.com/<твой-аккаунт>/kwork-sniper.git
cd kwork-sniper
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Создать Telegram-бота
1. Напиши [@BotFather](https://t.me/BotFather) → `/newbot` → получи **токен**.
2. Напиши своему новому боту любое сообщение (иначе он не сможет тебе писать).
3. Узнай свой **chat_id**: напиши [@userinfobot](https://t.me/userinfobot).

### 3. Заполнить конфиг
```bash
cp .env.example .env      # Windows: copy .env.example .env
```
Открой `.env` и впиши `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и нужные категории.

### 4. Выбрать категории
Посмотреть все коды:
```bash
python -m kwork_sniper.categories
```
Главный для ботов/парсинга/автоматизации — **`41` (Скрипты и боты)**.
В `.env`: `KWORK_CATEGORIES=41` (несколько — через запятую: `41,38,80`).

Можно указать **родительский раздел целиком** — например `11` = вся «Разработка и IT»
(вернёт проекты всех её подкатегорий). Чем шире раздел, тем больше страниц
сканируется за цикл (см. `MAX_PAGES`).

### 5. Запуск
```bash
python -m kwork_sniper
```
При первом запуске бот тихо запомнит текущие проекты и пришлёт «✅ запущен».
Дальше будет присылать только новые.

## Настройки (`.env`)

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather | — (обязательно) |
| `TELEGRAM_CHAT_ID` | Твой chat_id | — (обязательно) |
| `TELEGRAM_PROXY` | Прокси к Telegram (см. ниже) | пусто = напрямую |
| `KWORK_CATEGORIES` | Коды категорий через запятую | `41` |
| `KEYWORDS` | Ключевые слова (хоть одно в названии/описании) | пусто = все |
| `EXCLUDE_KEYWORDS` | Стоп-слова (отбросить, если найдено) | пусто |
| `MIN_BUDGET` | Минимальный бюджет, ₽ (`0` = выкл.) | `0` |
| `MAX_OFFERS` | Макс. число откликов/предложений (`0` = выкл.) | `0` |
| `MIN_HIRED_PERCENT` | Заказчик нанимает не менее X% (`0` = выкл.) | `0` |
| `MIN_CUSTOMER_PROJECTS` | У заказчика не менее N проектов (`0` = выкл.) | `0` |
| `POLL_INTERVAL` | Интервал опроса, сек | `75` |
| `MAX_PAGES` | Сколько страниц на категорию (`0` = все) | `0` |
| `DB_PATH` | Файл БД виденных проектов | `seen.db` |
| `LOG_LEVEL` | Уровень логов | `INFO` |

Совет для снайпинга: поставь `MAX_OFFERS=3`, чтобы ловить проекты с низкой
конкуренцией, и `KEYWORDS` под свои темы.

### Прокси (если Telegram заблокирован, напр. в РФ)

`api.telegram.org` в некоторых странах недоступен напрямую — тогда задай прокси
**только для Telegram** (Kwork опрашивается напрямую):

```
TELEGRAM_PROXY=http://user:pass@host:port      # HTTP-прокси
TELEGRAM_PROXY=socks5://user:pass@host:port    # SOCKS5-прокси
```

Если прокси выдан как `host:port:user:pass`, собери URL: `scheme://user:pass@host:port`.
Не уверен в типе — попробуй сначала `http://`, затем `socks5://`. Пусто = напрямую.

## Запуск 24/7

Бот следит только пока запущен. Варианты постоянной работы:

- **Windows** — «Планировщик заданий» (Task Scheduler): задача «при входе в систему»,
  действие — запуск `python -m kwork_sniper` в папке проекта.
- **Linux (VPS) — systemd:**
  ```ini
  # /etc/systemd/system/kwork-sniper.service
  [Service]
  WorkingDirectory=/path/to/kwork-sniper
  ExecStart=/path/to/kwork-sniper/.venv/bin/python -m kwork_sniper
  Restart=always
  [Install]
  WantedBy=multi-user.target
  ```
  `sudo systemctl enable --now kwork-sniper`
- **screen/tmux** — на любой always-on машине.

## Безопасность

- `.env` и `*.db` уже в [`.gitignore`](.gitignore) — **проверь перед `git push`**,
  что в коммит не попали реальный токен и база.
- Никаких внешних адресов: бот ходит только на `kwork.ru` и `api.telegram.org`.
- Если случайно закоммитил токен — немедленно отзови его в @BotFather (`/revoke`).

## Возможные проблемы

| Симптом | Причина / решение |
|---|---|
| `Не заданы обязательные переменные` | Не заполнен `.env` (токен/chat_id). |
| Бот молчит | Напиши боту первым; проверь `chat_id`; смотри логи. |
| `Ответ не JSON` / `success != true` | Kwork временно отдаёт HTML/антибот — бот сам уйдёт в backoff и продолжит. Если надолго — увеличь `POLL_INTERVAL`. |
| Дубли после смены `DB_PATH` | Это новая пустая база — будет повторное «засеивание». |
